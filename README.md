MiniDMart

MiniDMart is a full-stack grocery shopping application.

Technologies
Frontend: React.js
Backend: Spring Boot
Database: MySQL
Authentication: JWT

Features

User Login & Registration
Product Management
Product Search
Category Management
Add to Cart
Manager & Staff Authentication
REST APIs

Project Structure

mini_mart/
├── Frontend/
└── Backend/

Run the Project

Frontend
  cd Frontend
  npm install
  npm run dev
Backend

Run the Spring Boot application from the Backend folder.
